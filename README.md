# Tic Tac Toe

A two-player Tic Tac Toe game built with HTML, CSS and vanilla JavaScript.

## Features
- Two players (X and O) take turns on one device
- Shows whose turn it is
- Finds a winner across all 8 lines and highlights the winning boxes
- Detects a tie when the board is full
- **New Game** button appears when a round ends
- Glass-style board on a gradient background, works on mobile

## Run it
Open `index.html` in any browser. No build step or install needed.

## Project structure
```
index.html      # layout: status bar, 3×3 board, New Game button
styles.css      # styling
index.js        # game logic: turns, win and tie checks, reset
assets/         # background image and favicon
```

## Tech
HTML5 · CSS3 (Grid, Flexbox) · JavaScript (ES6)
